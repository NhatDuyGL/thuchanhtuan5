# BookStore Flexbox Practice

Ứng dụng React Native/Expo hoàn thành các bài thực hành layout Flexbox:

- Header cố định và Book Card dạng hàng ngang.
- Category Chips dùng `flexWrap` và `gap`.
- Book Grid 2 cột bằng Flexbox thuần.
- Badge giảm giá và Floating Cart Button bằng `position: absolute`.
- Home, Detail, Cart và Bottom Tab Bar.
- Dữ liệu dùng chung trong `data.js`.

## Chạy dự án

```bash
npm install
npm start
```

Ứng dụng không dùng thư viện navigation; chuyển màn hình bằng `useState` để tập trung vào layout.
